# 第十一章 写作前思考单（内部，不输出内部推理）

本章不是执行表，不输出内部推理；有出处的内容记忆与公开交接可以保存；程序校验证据匹配和版本，不验证思考完整性。它只是读完理论后、动笔前，在思考里要过一遍的
问题。想完即放下，不写出来，不引用，不进入正文。

## 11.1 动笔前在思考中回答

- 这次要写什么，要改变读者的什么；
- 材料是谁知道的、通过什么途径、此刻为什么说、可能只知道多少；
- 谁在看、为了什么看、有意不写什么；
- 哪些判断确定、哪些是推测、哪些保留，错了付出什么；
- 这篇是谁在说：词汇层级、句流、冷热、幽默、停顿、隐瞒方式；
- 哪些人名、术语、口癖、意象、伏笔和有功能重复必须稳定；
- 第一句想落在什么位置，最后一句想让读者停在什么感觉上。

## 11.2 润色时在思考中回答

- 从原文反推，这位作者知道什么、在乎什么、声音是什么；
- 哪几处只是没写到位：断了、硬了、凉了、空了、说多了；
- 哪些句子、重复、排版是作者本来就要的，必须一字不动；
- 改过的与没改过的放在一起，接缝在哪里。

## 11.3 内容核对与公开交接

humanize_guard 可辅助核对锚点和文字完整性，不能证明全部语义无损。结合原文检查事实、视角、声音与用户要求；必要时查记忆出处和冲突。

有实质进展或暂停前，可保存公开 checkpoint，记录交付、下一步和未知事项。需要长期保留的事实另以有出处的 memory 保存。不要把私有推理写入这些记录，也不要求每次写作都填满一张表。
