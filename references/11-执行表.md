# 第十一章 可直接填写的中文执行表

本章是"强制填表"的字段定义。诊断阶段必须按这些表逐格填写，每格引用原文，不得写空话。

## 11.1 段落诊断表

| 字段 | 填写内容 |
|---|---|
| 段落编号 | 原文中的稳定编号 |
| 文本类型 | 论述、说明、叙述、描写、对话等 |
| 段落任务 | 本段实际改变什么 |
| 说话者或视角 | 谁在表达或感知 |
| 知识来源 | 观察、记录、引用、推断、回忆等 |
| 已知信息 | 读者和人物已经知道什么 |
| 新信息 | 本段真正新增什么 |
| 焦点 | 最需要突出的内容 |
| 逻辑关系 | 并列、因果、条件、修正等 |
| 指称链 | 人名、代词、省略对应谁 |
| 事件体貌 | 开始、持续、完成、经历等 |
| 句型与构式 | 基本句型和有标记构式 |
| 重复功能 | 指称、强调、回环或机械复述 |
| 声音与语域 | 是否符合当前叙述声音、人物和发表场景 |
| 跨层路径 | 多个特征构成的稳定路径 |
| 保护内容 | 不得改变的事实和关系 |
| 修复尺度 | 词项、句流、信息、段落、声音、场景或结构 |
| 修改理由 | 为什么改，语言功能是什么 |

## 11.2 构式许可表

| 字段 | 填写内容 |
|---|---|
| 构式名称 | 准备使用的结构 |
| 语义前提 | 必须成立的事实关系 |
| 话语功能 | 焦点、对比、引入、处置等 |
| 视角影响 | 哪个参与者被置于中心 |
| 语域许可 | 作者、人物和场合是否允许 |
| 共现限制 | 与否定、情态、体貌的关系 |
| 歧义风险 | 是否可能误读 |
| 选择理由 | 为什么优于无标记形式 |
| 普通替代 | 不使用该构式时怎样表达 |

## 11.3 人物声音表

| 字段 | 填写内容 |
|---|---|
| 人物 | 姓名或稳定编号 |
| 社会位置 | 年龄、职业、教育、地域、权力 |
| 与听者关系 | 亲疏、上下、敌友、利益关系 |
| 当前压力 | 此刻逼迫人物的力量 |
| 表面目的 | 人物愿意让别人知道的目的 |
| 隐藏目的 | 人物实际想得到或避免什么 |
| 知识限制 | 不知道、误解或隐瞒什么 |
| 常用词汇 | 稳定但不过量的词汇倾向 |
| 句流习惯 | 简短、绕行、反问、停顿等 |
| 称谓系统 | 对不同人物如何称呼 |
| 禁忌表达 | 不愿或不会说什么 |
| 回避方式 | 转移、反击、沉默、含混等 |
| 修正方式 | 如何改口或承认错误 |

## 11.4 叙事十维审计表

| 维度 | 必填问题 | 高风险默认形态 | 改写依据 |
|---|---|---|---|
| 人物 | 如何出场、如何表达情绪、动机显隐如何 | 外貌出场、持续身体化、内心全解 | 当前任务、行为后果、知识缺口 |
| 社会网络 | 权力、债务、亲疏、信息差如何变化 | 配角只服务主角、关系由旁白宣布 | 言语行为、称谓、资源交换 |
| 事件 | 事件类型、密度、升级是否变化 | 匀速升级、同一解决链 | 冲突方式、误判、非情节后果 |
| 情节 | 主线、支线、解决权、道德位置如何 | 单线、无支线、主角顿悟收束 | 多线关系、共同因果、未决余波 |
| 篇章组织 | 章节和场景分别改变什么 | 每章同一开合、段尾总结 | 不对称任务、跨段承接 |
| 场所 | 地点如何限制或提供行动 | 清楚落地加精细描写、环境映心 | 观察目的、资源、阻碍、误读 |
| 时间 | 顺序、时长、频率如何组织 | 绝对顺叙、回忆只补背景 | 揭示收益、重释旧信息 |
| 揭示 | 谁何时知道，揭示改变什么 | 线索阶梯、一次说明闭环 | 知情差、旧场景重释、余留问题 |
| 叙述视角 | 谁看、能知道什么、怎样对待读者 | 无来源全知、所有解释同距离 | 焦点、叙述距离、信息许可 |
| 语言风格 | 词句节奏如何服务上述九维 | 统一精致、统一口语、罕见式注入 | 信息结构、人物、语域和节奏 |

## 11.5 原理层自检记录表

| 字段 | 填写内容 |
|---|---|
| 自检周期 | 同一入口和同一方法状态的时间段 |
| 文本编号 | 可复现的窗口或章节编号 |
| 文本类型 | 文章、小说、评论、说明等 |
| 取样边界 | 完整段落、论证单元、场景或章节 |
| 字符数 | 同轮保持一致 |
| 版本 | 原版、单模块版、合并版、留出版 |
| 唯一改动模块 | 本轮只允许一个可归因模块 |
| 原理层自检结果 | 对照第十四章七类信号的排查结论 |
| 读者证据 | 引用产生怀疑或消除怀疑的原句 |
| 编辑证据 | 具体结构、逻辑、文风或叙事问题 |
| 内容损伤 | 无、轻微、明显、不可接受 |
| 决策 | 保留、回退、扩大样本、转查其他模块 |
