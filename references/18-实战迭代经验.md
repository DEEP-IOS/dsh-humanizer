# 第十八章 实战迭代经验（v4—v6 实测）

> 来源：某第一人称中医悬疑小说 93—120 章 v4（60.55%）→ v5（31.94%）→ v6（高分切片逐一定点修复）三轮实测。
> 这是一部**第一人称中医悬疑小说**的实战经验。**具体阈值（"像"≤6/章等）是该项目级的，不是普适配额**；但七类高危模式的**类别**、细纲轮换**原则**、修复操作规程、脚本核验**思路**，是跨体裁可用的。
>
> **最重的一条警示（全文灵魂）："配额＝新指纹"。** 把任何手法做成每章配额（每章一处重释、每章一处命名情绪、每章一个钩子），28 遍复制同一配方，词句层再达标也照样 60.55%。**本插件自身也不得沦为固定配方。**

## 一、时间线与关键结论

| 版次 | 主要动作 | 加权AI率 | 说明 |
|---|---|---|---|
| v4 | 每章套"顺叙+重释+命名情绪一处+认知修正一处+钩子结尾"配方 | 60.55% | 词句层达标，失败在章节级配方模板化 |
| v5 | 细纲重建：章节任务四类轮换、时间六式、结尾五式、对话语用分工、去配额化 | 31.94% | 大块变绿，剩 16 个高分切片集中在 7 类高危模式 |
| v6 | 16 个高分切片逐一定位修复（18 处） | 待测 | 修复点已脚本核验清除 |

**关键结论一**：v4 词句层完全达标（平均句长 21.9 字、长句 23.1%、词频合格），检测结果仍 60.55%。**词句层是必要不充分条件，章节级叙事模板才是主战场。**

**关键结论二**：v5 把加权从 60.55% 压到 31.94%，**只靠细纲层的叙事设计多样化，正文语言约束几乎没变**。叙事设计是最大杠杆，语言是第二杠杆。

## 二、v4 失败根因：章节级配方模板化

v4 每章都填同一套十六字段细纲，表面"按经验做"，实际 28 遍复制同一配方：

1. 时间结构全是"顺叙+中段一处回看"；
2. 每章都有"重释点一处"——从叙事功能变成例行公事；
3. 每章都有"直接命名情绪一处"——"我是怕的/我是寒心的"成束出现（全卷 6 处同格式）；
4. 每章都有"认知修正一处"——"我先前还想着……"套路重复（全卷 8 处）；
5. 每章结尾都是钩子——钩子密度 100%；
6. 对话以"问-答"信息交换为主，缺拒绝/岔开/沉默/试探（v4 全卷 210 个问句）。

**判断方法：不看单章是否"达标"，看全卷是否把同一组特征做成了配额。配额＝新指纹。**

## 三、v5 细纲重建原则（写新章节的核心方法）

### 3.1 章节任务四类轮换
每章只承担一类主任务，禁止每章"事实+关系+解释+风险"全要素：**事实章**（改变读者知道什么）、**关系章**（改变人物关系）、**解释章**（改变旧材料含义）、**风险章**（改变局面压力）。连续两章不得同任务。

### 3.2 时间结构六种轮换
顺叙、倒叙主体、昏迷时间变形、延迟补叙、时间空缺、双线交叉。禁止连续两章同构；"顺叙+中段一处回看"最多每隔三四章用一次。

### 3.3 结尾五式轮换
动作收、物件收、悬念收、对话收、平收。**钩子占比压到四成**。平收章结尾允许带人物口吻的主题句，禁止无指涉的空泛升华。

### 3.4 对话语用分工
每章对话承担不同言语行为，不做问-答流水：拒绝回答、岔开、沉默、试探、威胁、机锋留白。对话变化来自言语目的，不来自"嗯啊那个"。

### 3.5 去配额化（最重要的一条）
"直接命名情绪"和"认知修正"不再是每章配额：
- 命名情绪：需要时用动作（手抖/掌心发凉）、停顿、物件承载；
- 认知修正：全部由**物件自证**或**他人行为自证**，不写"我这才明白/我先前以为"。

### 3.6 支线跨章延续
支线是跨章的物件与人物线，不每章塞新支线；物件链按信息结构自然回收。

## 四、v5 正文语言约束（已验证有效，但阈值是项目级的）

无破折号；半角引号 0（全角引号成对）；"像"≤6/章；"可"转折≤5/章；"忽然"≤2/章；"心里"≤5/章；"仿佛/似乎"≤2 全卷；"不是…而是"≤1 全卷；"我是X的"全卷 0；心理套路≤3；无解说总结句；禁三连排碎句（对话行除外）；叙述句法平均 20—24 字、30 字以上长句 20—26%、标准差 15+。

> 这些数字是**该项目的实测基线**，搬到别的题材需重新标定，不可照抄为普适配额。

## 五、v6 七类高危模式（本文件核心经验）

16 个高分切片定位后归纳出七类，每类给识别特征、体系依据、修复手法。

### 模式一：对话"问-答"流水（最高危，切片达 0.79）
- **识别**：连续多轮标准问答，每问必答、答得整齐、无打断无沉默；只交换信息，不改变关系。
- **依据**：§4.15"对话每问必答=异常"；§9.11"对话频繁承担信息交换"。
- **修复**：问答间插动作打断（续茶/盖油布/弯腰）、不接话、沉默、岔开；部分问句改陈述；答话带个人利益和立场。

### 模式二：对仗排比/回环句式
- **识别**："不是X，是Y"整句对仗；"求粮，求的是我们的粮。求将，求的是窦临的将"式回环；整齐三连。
- **依据**：§16.4 对称排比；§16.5 否定转高阶。
- **修复**：拆对仗为单句递进或让步；回环只保留一处有节奏功能的位置；信息不变、结构打散。

### 模式三：心理解释旁白/心理代理
- **识别**："可我能感觉到他在看我""眼神里有点什么东西""像是意识到说多了"——叙述者对人物心理做无来源的全知解释。
- **依据**：§16.2 心理动词代理；§9.9 不做无来源全知解释。
- **修复**：删心理代理句，改由动作、物件、对话自证；确需保留的心理概述只用于过渡，不用于关键场景。

### 模式四：微动作连续堆砌
- **识别**："手指摩挲了两遍""指甲剪得整整齐齐""嘴唇动了动"同一段内两处以上同类微动作。
- **依据**：§9.1 情绪持续身体化；§9.11 内心进入持续过深。
- **修复**：每段保留至多一处有信息量的微动作；其余删或改行为/对话。

### 模式五：环境细描/怀旧模板
- **识别**："渡口曾经繁华过，如今只剩半截栈桥"式怀旧环境；开篇环境+感官+心理三件套。
- **依据**：§9.6 场所只写人物会注意/使用/误判的部分；§9.11 开篇空间定位过齐。
- **修复**：环境只留功能件；删"曾经繁华过"类无功能怀旧；开篇从动作或对话切入。

### 模式六：枚举骨架
- **识别**："同一条路，在同一个铺子买同一种饼"式三连枚举；"账，供状，船册，私印"式清单；"三样东西……"式总结枚举。
- **依据**：§8.2 整齐列举。
- **修复**：枚举拆成有先后、有变化的动作；清单改逐样放置的具体动作。

### 模式七：意象化收尾/升华
- **识别**：章尾"风从城北吹过来……天亮了"式环境意象收束；重复使用的同款意象句。
- **依据**：§16.14 结尾自动升华。
- **修复**：结尾改具体动作（扣铜扣/合匣/推窗），删重复意象；意象句全文只允许一个位置出现。

### 补充观察：高分切片分布规律
- 高分切片多为小块（260—1886 字），大块文本（2000 字+）几乎全绿；
- 优先修大权重块，收益最大；
- 对话密集章贡献了大部分高分切片，**对话是连写时的主要雷区**。

## 六、修复操作规程（v6 用，此后同样适用）

1. 先定位再修：提取每个切片序号、值、权重、原文，定位到章节；
2. 按权重排序：优先处理权重大的高分切片；
3. 每片归类：对照七类模式标注所属模式；
4. 逐片定点修：一次只改一个切片内的文本，不改相邻绿块；每处写明语言功能理由；
5. 修完脚本核验：破折号 0、半角引号 0、全角引号成对、"我是X的"0、修复点原文全部消失；
6. 保留对照：修复版另存新文件名，原版保留供最小差异对照；负优化立即回退；
7. 绿块不动：AIGC 低的切片禁止顺手"优化"。

## 七、脚本验证清单（每次修改后必跑）

```
1. 破折号—— 计数 = 0
2. 半角引号 " 计数 = 0；全角引号"“"”"成对（数量相等）
3. "我是X的"（我是[^，。]{1,8}的）= 0
4. 我这才明白/知道 ≤ 3；我先前/本来/当时 = 0；意识到 ≤ 2；才想明白 ≤ 1
5. 仿佛/似乎 = 0；不是…而是（不是.{0,6}而是）≤ 1
6. 逐章：破折号0、像≤6、忽然≤2、心里≤5
7. 叙述句法（剔除引号内容后按。！？切分）：平均20—24字、30+长句20—26%、标准差15+
8. 章节标题数正确；无章节缺失
```

## 八、写作基准汇总（121 章起）

1. 每章先写细纲，必含：章节任务（四选一，连续两章不重复）、时间结构（六式轮换）、结尾方式（五式轮换，钩子≤四成）、对话语用（本轮承担哪种言语行为）；
2. 正文约束按本文件第四节（阈值项目级标定）；
3. 认知修正由物件/动作/他人行为自证，每处认知必须能回答"由什么物证/行为自证"；
4. 对话承担关系行为（拒绝/岔开/沉默/试探/威胁/讽刺/让步/辩护轮换），不做问-答流水；每章对话至少一处"不答/岔开/沉默"；
5. 微动作每段至多一处；环境只写功能件；枚举拆动作；意象句全文唯一；章尾禁自动升华；
6. 支线跨章延续，不每章塞新支线；
7. 每 5 章复测一次，按七类模式定位再修；坚持最小差异对照，一次只改一个模块，负优化立即回退。
