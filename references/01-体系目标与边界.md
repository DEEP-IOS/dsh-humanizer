# 第一章 体系目标与边界

> 主版本：二〇二六年八月版
> 适用对象：现代汉语文章、评论、说明、论文性文字、非虚构写作、故事与小说

## 1.1 同时实现的五个目标

本体系不是简单的"去除人工智能常用词"，而是同时追求五个不能互相替代的目标：

1. **人类作者感**：读者能够感到文本背后存在具体的观察者、判断者、叙述者或人物，而不是一个无位置的说明装置。
2. **语言分布异质性**：文本不长期集中于单一词汇、句型、复句、段落和推理路径，但所有变化都有语义和语用理由。
3. **内容忠实性**：事实、观点、论证、人物、视角、因果、时序、伏笔和专业术语不得因改写受损。
4. **自动审核通过性**：尽可能降低人工智能生成嫌疑（本插件不要求使用者提交外部检测，但方法必须从原理层对抗检测器）。
5. **人工审核通过性**：普通读者和职业编辑在不知道文本来源时，不能从结构、逻辑、表达习惯、文风和叙事设计中形成稳定的人工智能怀疑。

本体系的目标不是证明真实作者身份，也不要求文本符合某位作者过去的作品。目标检测器、普通读者和编辑都不知道作者是谁，因此"与作者历史样本相似"不构成主任务，也不得消耗核心流程。需要保持的是当前文本内部的声音连续、人物区分和体裁适配。

## 1.2 不可承诺的事项

- 不承诺任何检测器必然给出接近零的判断。
- 不承诺不同检测器产生一致结论。
- 不把检测结果等同于真实作者身份。
- 不把任何检测器的未公开模型结构、特征权重和阈值当作已知事实。
- 不通过病句、错别字、乱码、随机关联词或无意义生僻词换取结果变化。
- 不把"更复杂"当成"更像人类"的同义词。

## 1.3 主版本原则

方法主版本唯一。其他格式只能由主版本派生，不得在派生版本中新增、删减或改写方法。方法更新必须先进入主版本，再生成其他格式。

（本插件为方法的执行载体：本章其余内容——目标与边界——是下面十六章的总纲，执行任何一步前都应回到这五条目标与六条不可承诺核对。）
