# v0.4：可恢复的写作工作台

目标是改善长篇写作、连续润色的事实一致性、作者声音和交接，不把“记忆工具存在”当成模型已经理解，也不宣称未经对照评估的全球最佳。

## 现有问题

v0.3 的工具不保存项目和任务；完整理论靠一次长结果进入上下文，压缩后没有恢复入口；“不产工件”同时禁止了有用的交接记录。程序也无法区分模型已经读过、真正理解、实际采用三个不同的事实。

## 设计选择

1. 内容记忆用本机 SQLite 存储，不要求 Neo4j、向量服务、额外 API Key 或外部模型。每个工作区和作品隔离，作品内部把人物/概念作为节点，把带证据的关系作为边；实体匹配加一跳关联召回，固定预算内装入上下文。
2. 每条记忆保留来源标签、原文引文、来源文本哈希、记录时间和可选的故事时间。引文必须出现在本次提供的来源文本里；这证明引用对应，不能证明来源本身真实或模型理解正确。
3. 推测以 inferred 单独标记，会随相关结果返回；模型必须按标注使用，程序不自动判真或排除；同一 key 的关系出现不同说法时留下冲突；不同 key 间尚不做语义冲突检测，不能静默覆盖。明确修订需携带旧版本号；遗忘操作清除正文和历史引文，不只隐藏检索结果。
4. 当前任务与下一步是公开可检查的交接记录，禁止保存模型隐藏思维链。会话绑定作品，宿主每次组装上下文时重新取出交接记录；使用官方动态 user-role context，让它随宿主记录进入会话。
5. `humanize_prepare` 同时恢复记忆、保存任务，并返回与体裁/当前问题相关的完整理论章节。原来的 `humanize_study` 保留全部 21 章，深读随时可用。理论导航不冒充全部理论，更不声称程序能验证理解。
6. `humanize_memory` 管理召回、记录、冲突修订、历史和遗忘；`humanize_checkpoint` 保存实际进度与未解决问题。用户用自然语言提出需求，不必手工填图谱或写 JSON。
7. 正文仍然自由写作。机械守卫只核对明确可核对的事实/文字问题；记忆不规定句长、词频、桥段配额或每章统一结构。

## 边界与后续评估

首版采用带来源的关系图和确定性检索。它不会自动正确地理解整部长篇，不会把一个章节返回成功写成“模型已经掌握”，也不会用关键词命中率冒充文笔提升。对中英文别名、隐含关系和语义改写，后续可增加可替换的检索后端，但保留本地无服务的默认体验。

上线前分别验证持久化与重启、工作区/作品隔离、跨连接写入、冲突和时间版本、遗忘、预算截断、宿主上下文自动恢复，以及三版本 DSH 的真实生命周期。写作效果另用公开样例做原版/新版盲评，比较事实错误、作者声音、自然度、修改必要性和使用成本；未做模型盲评时不报告优胜结论。

## 研究依据

- [Lost in the Middle](https://arxiv.org/abs/2307.03172) 表明，较长上下文不保证信息能被同样可靠地利用；它支持减少无关上下文的设计动机，不直接证明本插件改善了文笔。
- [LongMemEval](https://arxiv.org/abs/2410.10813) 将提取、跨会话推理、时间推理、知识更新与不知道时不作答分开评估；本插件据此拆分记忆测试，避免只测试“能写入/能读出”。
- [Zep 的时间知识图架构](https://arxiv.org/abs/2501.13956) 提供了来源与时间关系的工程参考；本插件不复用其实验结果作为自身成绩，也不直接引入其服务依赖。

## 具体状态与容量

每个 key 有 active、conflict 或 forgotten 状态；不同来源支持同一语义元组可保持 active。remember 最多保留 8 个当前候选，包含佐证；revise 用当前版本显式替换候选，历史仍保留。forget 清除该 key 的历史负载后保留墓碑，普通 remember 不可恢复墓碑。每作品 5000 个 key 包含墓碑；history 只返回最近 100 版，数据库历史总量不以 100 封顶。

召回加载作品当前记录，做字面匹配与一跳扩展；无别名自动归一、向量检索、跨 key 矛盾检测或时间推理。pinned 提升优先级，超出 9000 字符 JSON 预算的记录整体略过。omitted 只数预算遗漏的候选，total 是全部未遗忘记录数。

## 会话与交接

工作区来自真实目录，同一 DSH_HOME 下不同作品分开。新会话先 prepare；相同会话、作品和 task 幂等返回。新任务优先沿用当前会话该作品的交接，没有时取该作品最近更新的会话绑定，不合并多个并行会话。

checkpoint 的版本是 task.revision，记忆修正版本是 record.revision，两者不能混用。complete 不解绑、不自动将 draft 升为 canon。没有被保存的信息不能凭空恢复。
