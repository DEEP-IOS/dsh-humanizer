# 质量验证：机制测试与成稿盲评分开

## 当前可以确认的部分

`pnpm test` 验证确定性的存储、关系检索、修订和恢复行为。`test/integration/smoke-profile.mjs` 使用真实 DSH 工具运行时、Session、systemPrompt 与 PTC worker，验证用户角色资料恢复以及 Web 安装生命周期。测试不运行生成模型，不能证明模型会正确选取记忆、理解长篇或写出更自然的文字。

`node --input-type=module -e "import {prepareReading} from './lib/prepare.mjs'; for (const t of ['fiction','article','mixed']) { const r=prepareReading(t); console.log(t,r.selectedCharacters,r.fullCharacters) }"` 可复现按需理论的输入字符数。它不是实际 token 账单或写作质量提升率。

## 公开、可复现的成稿评测

比较基线 `0.3.0-rc.2`、当前版本、同模型无插件三个条件。固定模型完整版本、温度、最大输出、任务、材料与模型服务；每条件使用全新 DSH_HOME 与会话，至少三个独立重复。记录源提交、宿主版本、完整提示、工具轨迹、输入输出 token、时间和错误。失败运行计入结果，不能只保留好文章。

优先选六类自有版权或公开许可任务，每类至少五个不同材料，并预先列出不能丢失的事实与明确的声音依据：

| 任务 | 设置 | 重点观察 |
|---|---|---|
| 跨章续写 | 首章埋伏笔，中间加入无关讨论，压缩后继续 | 已知关系、未回收伏笔、人物知识边界 |
| 作者改设定 | 初稿师父是老林，后有明确修正，重启后续写 | 使用有效修正，避免新旧混用 |
| 时间与设想 | 青年和晚年职业不同，计划中另有职业 | 不同时点不互相覆盖，计划不当已发生 |
| 多作品隔离 | 两部作品都有同名人物，交替会话 | 不从另一部小说偷取设定 |
| 声音保留 | 冷硬、幽默、克制三种有原文样本的声音 | 文风不趋同，不复制示例模板 |
| 文章润色 | 含数字、人名、证据限制与有功能重复 | 语义忠实，只改确有必要处 |

每份成稿随机分配盲编号、随机左右位置，由至少三名不知道版本的读者独立判断：

- 自然度：是否出现无法由材料解释的模板句或生硬衔接。
- 忠实度：是否增删事实、越过证据边界、改变人物知识或叙述视角。
- 声音：是否延续提供样本中的说话方式、在乎与克制程度。
- 修改必要性：润色是否有多余换词、拆段、升华或意义漂移。
- 连续性：是否引用了有效记忆，遇到矛盾和未知是否适当保留。

记录成对偏好（A/B/平局）和支持判断的具体句子，保留读者分歧。发布各类任务结果与置信区间，不把内部质量评价包装成 AI 概率。评审不应因用了图谱或工具多就奖励文本。

发布“质量更好”的结论前，应达到：关键事实没有新增回归，跨作品无泄漏，恢复任务正确，盲评在多个体裁中方向一致，并公开成本变化。否则继续修复具体失败。没有足够公开比较时，不使用“全球最好”的事实性宣传。

## 设计依据

[Lost in the Middle](https://arxiv.org/abs/2307.03172) 支持检视长输入位置和干扰对检索的影响；本文据此选择按需原文和有限召回，不声称该论文验证了本插件。

[LongMemEval](https://arxiv.org/abs/2410.10813) 的跨会话、更新、时序和不确定性维度启发上述用例；本插件没有运行该基准，不能引用其分数为自身成绩。

[Zep 的时间知识图谱论文](https://arxiv.org/abs/2501.13956) 提供可追溯关系记忆的设计参考。本版本采用简化的本地关系存储和显式故事时点，未实现该系统的语义检索或自动时间推理。
